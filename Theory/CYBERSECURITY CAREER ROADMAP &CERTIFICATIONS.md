# **CYBERSECURITY CAREER ROADMAP**

## **1. Core Cybersecurity Domains**

| Domain                                    | Focus                                      | Example Roles                             |
| ----------------------------------------- | ------------------------------------------ | ----------------------------------------- |
| **Network Security**                      | Protect networks, firewalls, VPNs, IDS/IPS | Network Security Engineer, Firewall Admin |
| **Application Security (AppSec)**         | Secure SDLC & software                     | AppSec Engineer, Web Security Analyst     |
| **Cloud Security**                        | AWS, Azure, GCP environments               | Cloud Security Engineer                   |
| **Endpoint Security**                     | Manage EDR, antivirus, devices             | Endpoint Protection Specialist            |
| **Security Operations (SOC)**             | Monitoring, threat detection, response     | SOC Analyst, Incident Responder           |
| **GRC (Governance, Risk, Compliance)**    | Policies, audits, standards                | Compliance Analyst, Risk Manager          |
| **Digital Forensics & IR (DFIR)**         | Investigate breaches                       | Forensic Investigator                     |
| **Penetration Testing / Ethical Hacking** | Simulate attacks                           | Ethical Hacker, Red Team Specialist       |
| **Identity & Access Management (IAM)**    | Control access to systems/data             | IAM Analyst, Identity Architect           |
| **Security Architecture & Engineering**   | Design secure systems                      | Security Architect                        |

## **2. Career Levels**

| Level              | Experience | Focus                                     | Example Roles                                        |
| ------------------ | ---------- | ----------------------------------------- | ---------------------------------------------------- |
| **Entry-Level**    | 0–2 yrs    | Basic IT & security fundamentals          | SOC Analyst I, Security Technician, Junior Pentester |
| **Mid-Level**      | 2–5 yrs    | Technical specialization & certifications | Security Engineer, Threat Hunter, GRC Analyst        |
| **Advanced-Level** | 5+ yrs     | Leadership, strategy, governance          | Security Architect, SOC Manager, CISO                |

---

## **3. Roadmap Steps**

1. **Build IT Fundamentals**

   * Networking: TCP/IP, DNS, routing
   * OS: Windows, Linux, macOS
   * Programming: Python, PowerShell, Bash, SQL
   * Hardware & system architecture basics

2. **Learn Cybersecurity Basics**

   * CIA triad, common threats
   * Tools: Wireshark, Nmap, Burp Suite, Metasploit
   * Firewalls, antivirus, proxies, SIEM

3. **Choose Career Track**

   | Track      | Focus                                | Example Roles                   |
   | ---------- | ------------------------------------ | ------------------------------- |
   | Technical  | Hands-on defense, hacking, forensics | SOC Analyst, Penetration Tester |
   | Management | Policy, risk, audit, governance      | Security Manager, GRC Officer   |

4. **Get Certified** – validate skills to employers

5. **Gain Experience** – internships, labs, CTFs, home labs (VirtualBox, TryHackMe, HackTheBox)

6. **Specialize & Grow** – Threat Hunting, Cloud Security, IR, Security Architecture

| Cert                             | Issuer          | Focus                                | Ideal For              |
| -------------------------------- | --------------- | ------------------------------------ | ---------------------- |
| CompTIA Security+                | CompTIA         | Core security fundamentals           | Beginners              |

| EC-Council CSCU                  | EC-Council      | End-user awareness                   | Non-technical roles    |
| Google Cybersecurity Certificate | Google/Coursera | SOC basics                           | Beginners              |

### **Intermediate-Level**

| Cert                     | Issuer     | Focus                       | Ideal Role         |

## **6. Example Career Paths**

1. **SOC Analyst → Threat Hunter → SOC Manager**
   Security+ → CySA+/GCIH → CISSP/SIEM specialization

2. **Ethical Hacker → Penetration Tester → Red Team Lead**
   CEH/eJPT → OSCP/PNPT → OSEP/OSEE

3. **GRC Analyst → Risk Manager → CISO**
   (ISC)² CC/ISO 27001 LA → CISM/CRISC → CISSP + Executive Experience
